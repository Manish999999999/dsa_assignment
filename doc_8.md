# Question 8: Sorting Algorithms with Comparison and Swap Count

## Sorting Algorithms Used
- Bubble Sort  
- Selection Sort  
- Insertion Sort  

## Functions
- bubbleSort(): Sorts the array using Bubble Sort and counts comparisons and swaps.  
- selectionSort(): Sorts the array using Selection Sort and counts comparisons and swaps.  
- insertionSort(): Sorts the array using Insertion Sort and counts comparisons and swaps.  

## Main Function
- Inputs number of elements and array values.  
- Makes three copies of array for each sorting algorithm.  
- Calls all three sorting functions.  
- Displays sorted array along with comparisons and swaps.

## Sample Output
Enter number of elements: 5  
Enter elements: 5 2 4 3 1  

Bubble Sort: 1 2 3 4 5  
Comparisons: 10, Swaps: 6  

Selection Sort: 1 2 3 4 5  
Comparisons: 10, Swaps: 4  

Insertion Sort: 1 2 3 4 5  
Comparisons: 7, Swaps: 8

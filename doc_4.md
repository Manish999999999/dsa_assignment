# Question 4: Doubly Linked List Insert and Delete

## Data Structure Used
Doubly linked list is used. Each node has data, next, and previous pointer.

## Functions
- createNode(): Creates a new node.  
- insertEnd(): Adds a node at the end of the list.  
- deleteNode(): Deletes a node with given value.  
- printList(): Prints the list from start to end.  

## Main Function
Takes input from user to create list, prints it, deletes a node given by user, and prints updated list.

## Sample Output
Enter number of elements: 4  
Enter element 1: 10  
Enter element 2: 20  
Enter element 3: 30  
Enter element 4: 40  
List: 10 20 30 40  
Enter value to delete: 20  
20 deleted from list.  
Updated list: 10 30 40

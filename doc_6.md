# Question 6: Min Heap and Max Heap Implementation

## Data Structure Used
Heap (array-based implementation).  
Min Heap and Max Heap are implemented using simple insertion logic.

## Functions
- swap(): Swaps two numbers.  
- insertMinHeap(): Inserts an element in Min Heap maintaining heap property.  
- insertMaxHeap(): Inserts an element in Max Heap maintaining heap property.  
- displayHeap(): Prints all elements of the heap.

## Main Function
- Takes input for number of elements and their values.  
- User chooses Min Heap or Max Heap for each element.  
- Displays final heap elements.

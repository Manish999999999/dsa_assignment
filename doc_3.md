# Question 3: Reverse Traversal of Singly Linked List.

## Data Structure Used
A singly linked list is used to store elements. Each node contains data and a pointer to the next node.

## Functions Description
- createNode(): Creates and returns a new node with given data.
- insertEnd(): Inserts a node at the end of the linked list.
- printReverse(): Recursively prints the linked list elements in reverse order.

## Main Function
The main function asks the user for the number of elements, then inputs the elements to create the linked list. Finally, it calls printReverse() to display elements in reverse order.

## Sample Output
Enter number of elements: 5  
Enter element 1: 10  
Enter element 2: 20  
Enter element 3: 30  
Enter element 4: 40  
Enter element 5: 50  
Linked List in reverse: 50 40 30 20 10
